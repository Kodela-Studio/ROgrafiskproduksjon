# Rolf Ottesen – Grafisk Produksjon

Nytt nettsted utviklet av Kodela Studio.

## Foreslått struktur

- `index.html` – forside
- `tjenester.html` – tjenesteoversikt
- `arbeider.html` – utvalgte arbeider / referanser
- `om.html` – historie og om bedriften
- `kontakt.html` – kontakt og tilbudsforespørsel
- `css/` – stilark
- `js/` – JavaScript
- `assets/images/` – bilder
- `assets/video/` – hero-video
- `assets/logo/` – logoer
- `assets/icons/` – eventuelle ikoner

## Mediefiler som skal legges inn

- Logo: `assets/logo/rolf-ottesen-logo.png`
- Hero-video: `assets/video/rolf-ottesen-hero.mp4`
- Bilder: legg individuelle bilder i `assets/images/`

Prosjektet settes først opp som en statisk HTML/CSS/JS-side og kan utvides senere ved behov.
